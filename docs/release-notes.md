# What's New in Lyreline 1.3.2

Lyreline 1.3.2 focuses on clarity, discoverability, and confidence from capture
through publication.

## Capture the right source with more confidence

The source picker now supports:

- **All / Windows / Applications** filtering;
- search by application and window title;
- grouping by application; and
- explicit **APP** and **WINDOW** labels.

During capture, **Active Capture Target** shows what Lyreline will capture.
After a new moment is added, **Last Captured Moment** provides immediate
confirmation and source context.

## A clearer workflow

Lyreline now describes the authoring flow consistently as:

**Capture → Organize → Procedure → Review & Finalize → Publish**

A **Capture Snapshot** is separate from publication. It is a read-only
historical checkpoint of a Capture Session. When one exists, the Capture
Session can show **Snapshot Saved** without implying that the linked Procedure
has been published.

## Reordering is easier to discover

Procedure Sections and Steps show visible **Drag to Reorder** handles. While
dragging, Lyreline shows an insertion indicator at the destination. Move Up and
Move Down controls remain available.

## Markdown export is easier to find

**Export Markdown…** now appears beside **Export PDF…** in the Procedure
toolbar.

- PDF is review-ready finished output.
- Markdown is an editable/interchange artifact for continued editing, source
  control, MkDocs, or re-import into Lyreline.

## Better editable-field guidance

Placeholder text now follows normal macOS styling more consistently. New
Procedure Steps no longer store instructional placeholder copy as authored
content.

## Multilingual text

Lyreline has been validated with multilingual Unicode text through:

- save and reopen;
- Markdown export and import;
- Lyreline → Lyreline Studio handoff; and
- PDF output.

Validated examples include Latin text with diacritics, Japanese, Chinese, and
Arabic.

## Compatibility

Lyreline 1.3.2 preserves existing document identities, capture semantics,
ordering behavior, archives, and saved user content.
