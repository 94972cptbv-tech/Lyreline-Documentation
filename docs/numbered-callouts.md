# Numbered Callouts

Numbered callouts connect parts of an image with the instructions that explain
them. They are especially useful when one screenshot contains several controls,
areas, or actions that need separate explanations.

## Parts of a numbered callout

A numbered callout can include:

- a **marker number** that identifies the annotation;
- an **optional label** that briefly describes the action or area;
- a **leader line** that connects the marker to the relevant location; and
- a **target** that shows the exact control or region being discussed.

Keep labels short and action-oriented. The instruction can provide the complete
explanation while the callout helps the reader find the corresponding place in
the image.

## Link a callout to an instruction

In Capture Presentation, a numbered callout can be linked to a specific
Procedure instruction. Use the **Linked Instruction** control for the selected
callout to choose the instruction it explains.

This relationship is helpful when a visual contains several numbered
annotations. Instead of relying only on visual order or nearby text, each
callout retains an explicit relationship with its intended instruction. More
than one callout can point to the same instruction when several areas of the
image support one action.

The marker number is a presentation choice. Renumbering or rearranging callouts
does not change which instruction a linked callout belongs to.

## Non-destructive presentation editing

Callouts, labels, leader lines, and targets are presentation edits. They do not
change the original captured image. You can move, resize, relabel, relink, or
remove a callout while keeping the original capture intact.

Document Preview and supported exports render the saved presentation rather
than modifying the source image.

## Continue through Lyreline Studio

Supported Lyreline Studio round trips preserve numbered callouts, optional
labels, and their instruction relationships with the authored procedure. This
allows advanced composition work to continue in Studio without losing the
meaning established between an annotation and its instruction.

Detailed handoff and publication instructions are provided in the separate
[Lyreline Studio documentation](https://94972cptbv-tech.github.io/LyrelineStudio-Documentation/using-with-lyreline/).
