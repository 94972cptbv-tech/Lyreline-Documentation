# Privacy Policy

**Effective date: August 2, 2026**

Lyreline is a macOS application for documenting workflows. Workflow screenshots
and authored content are processed locally on the user's Mac. Project data is
stored in Lyreline's application sandbox. Publications and archives are written
only to destinations selected by the user.

## Screen capture

Screen capture is user initiated. Lyreline uses Apple's system capture picker so
the user chooses the window or application to document. Lyreline does not record
the screen continuously.

## Safari workflow observation

The bundled Safari extension communicates locally with its containing Lyreline
application. Safari observation is disabled by default. It requires an active
Capture Session in the Recording state, explicit enablement in Lyreline, Safari
website permission, and a supported page.

Observation messages omit typed values, credentials, authentication tokens,
selected filenames, API results, and page-result content.

## Network services, analytics, and tracking

The Lyreline application does not upload captured workflow content to an
external service. It contains no analytics, advertising, tracking, or
third-party telemetry.

This statement describes the Lyreline application. This public documentation
website is hosted separately through GitHub Pages. GitHub's handling of website
requests is governed by [GitHub's Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement).

## Exports, archives, and deletion

Archive creation and publication export occur only after a user action and use
a user-selected destination. Normal deletion moves supported records to
Recently Deleted, where they can be restored. Permanent deletion provides an
archive-before-purge option and requires a separate exact typed confirmation
before data is removed.
