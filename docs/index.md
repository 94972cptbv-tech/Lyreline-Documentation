# Lyreline Documentation

Lyreline is a native macOS application for documenting repeatable work as it
happens. It combines user-initiated screenshots, written instructions, and
non-destructive presentation edits in resumable local projects.

Original image masters remain unchanged while crops, redactions, highlights,
labels, selected regions, and numbered callouts shape the published
presentation. Draft work can be saved, resumed, reordered, reviewed, archived,
restored, and exported as PDF, PNG, or portable Markdown.

Lyreline separates **Capture Sessions** from authored **Procedures**. Capture
Sessions preserve source material and history; Procedures contain the editable
instructions that can be reviewed, exported, or continued in Lyreline Studio.

## What's new in 1.3.2

Lyreline 1.3.2 improves capture-source selection, makes the active capture target
and most recent capture easier to verify, clarifies Capture → Procedure → Review
terminology, exposes drag-to-reorder controls, places Markdown export beside PDF,
and improves editable-field placeholder behavior.

Multilingual authored text has also been validated through save/reopen,
Markdown import/export, Lyreline Studio handoff, and PDF output.

See [What's New in Lyreline 1.3.2](release-notes.md) for details.
