Good to know

A few practical details.

Can I use either app on its own?

Yes. Each app works independently. Together, they connect procedure authoring with narration and instructional-media production.

Is there a subscription?

Both apps are one-time paid downloads, with no in-app purchases or app subscriptions. Optional OpenAI narration uses your own API access, with any OpenAI usage charges billed separately.

What Mac do I need?

Lyreline requires macOS 15.4 or later. Lyreline Studio requires macOS 14 or later. To use both, you need macOS 15.4 or later. Check each App Store listing for current compatibility.

Where can I find help?

Visit the Lyreline documentation or Lyreline Studio documentation for getting started, workflows, troubleshooting, and support information.
